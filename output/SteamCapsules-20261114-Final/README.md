# Steam kapsül seti

PNG klasöründe kesin yükleme ölçüleri: başlık 920×430, ana 1232×706, dikey 748×896, küçük 462×174.

Onaylanan küçük kapsülün görsel dili farklı oranlara yerleşik image_gen ile uyarlandı. Dikeyde Eri logonun üzerinde mutlu gözlerle oturur; harflerin hacmi, temas gölgeleri ve zemine düşen gölge aynı sahnede görünmesini sağlar. Yazı çizimle üretilmiştir. Yeni üçüncü taraf varlık/font indirilmedi. Unity entegrasyonu ve Steam yüklemesi yapılmadı.

source klasörü yüksek çözünürlüklü üretim kaynaklarını, design.json üretim istemlerini içerir. export.ps1 tam ölçülü PNG'leri mevcut System.Drawing ile üretir; manifest.json boyutları ve SHA-256 değerlerini kaydeder.
