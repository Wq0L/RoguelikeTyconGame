# Common — metal plaka

Tek tek ilerleyen yeni kart tasarımının ilk parçası. Aseprite ile çizildi.

- Common_Plate.aseprite: dört düzenlenebilir katman.
- Common_Plate.png: birleşik kart.
- Common_Frame.png: içi şeffaf metal plaka, vidalar ve işlenmiş detaylar.
- Common_Background.png: boş koyu iç zemin.
- Common_Shadow.png: ayrı dış gölge.

128 × 180 px. Unity: Simple, Preserve Aspect, Point, Compression None. 256 × 360 veya 384 × 540 gibi tam sayı ölçeklerde kullan. Menteşe ve gömme parçaların şekli korunması için 9-slice uygulanmadı.

Üst isimlik: x29–98, y15–20. Ana içerik için güvenli alan: x23–104, y36–144. Koordinatlar sol üst başlangıçlı kaynak piksellerdir. Uzun kart isimlerini ana içerikte göster; üst isimlik kısa kod/etiket için uygundur.

Önceki dört nadirlik tasarımı değiştirilmedi. Bu revizyon yalnızca Common kartıdır; sahnelere otomatik bağlanmadı.
