# EXE sahne geçişi çöküşü — 26 Eylül 2026

Kullanıcı doğrulaması: Editor'de çalışıyor; EXE'de Play sonrası çöküyor.

İncelenen build: `gamev0.04 optimizasyon test version/clickerTycon.exe`, Unity 6000.3.14f1, Mono, NVIDIA RTX 5080, driver 32.0.16.1692, Direct3D 12. Performans kaydı açık. Çökme öncesi günlükte managed exception yok; sahne yükleme/unused asset temizliği sonrasında native Crash kaydı var. Bu zaman sırası tek başına asset temizliğini suçlamaz.

## Sonraki kontrollü deneme

Aynı build klasöründe:

```bat
.\clickerTycon.exe -force-d3d11 -harvest-perf
```

Bu parametre yalnız o başlatmada D3D11 seçer; proje ayarını değiştirmez. Kaydın açık kalması ilk karşılaştırmada yalnız grafik API'sini değiştirmemizi sağlar. Play sonrası sahne açılışı ve birkaç tekrar kontrol edilmeli, Player.log içinde Direct3D 11 gerçekten seçilmiş mi doğrulanmalı. Başarılı olursa Windows build için D3D11 önceliği değerlendirilebilir; tek başarı kalıcı çözüm veya donanım arızası kanıtı değildir.

D3D11 de çökerse aynı API ile `-harvest-perf` olmadan deneme, yeni crash trace ve render pass izolasyonu gerekir. Henüz D3D11 denemesi gerçekleştirilmedi; hiçbir grafik/balance ayarı değiştirilmedi.

Unity parametre belgesi: https://docs.unity3d.com/cn/6000.0/Manual/PlayerCommandLineArguments.html
